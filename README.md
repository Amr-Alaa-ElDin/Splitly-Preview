# Splitly 💸

**Splitly** is a simple, no-nonsense app designed to take the headache out of sharing expenses. Whether you're splitting rent with roommates, splitting a dinner bill, or sharing costs on a group trip, Splitly automatically tracks exactly who owes what so you don't have to.

## ✨ Key Features

* **Group Expenses:** Create dedicated groups for roommates, trips, or events.
* **Smart Math:** Automatically calculates the easiest way to settle up, minimizing total transactions.
* **Activity History:** A clear, easy-to-read ledger of who paid for what.
* **Simple Interface:** Fast and intuitive, so you can add an expense in seconds.
